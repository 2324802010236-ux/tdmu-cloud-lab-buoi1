2. Kết quả thực hiện API Hello Cloud

Em đã sử dụng GitHub Codespaces để tạo môi trường lập trình trực tuyến và xây dựng API bằng Node.js kết hợp Express. API hoạt động trên cổng 3000 và trả về các thông tin của môi trường đám mây.

Thông tin API đã kiểm tra:

Kết quả: API hoạt động thành công.

API đã được kiểm tra thành công từ trình duyệt trên máy tính và điện thoại. Sau khi thử truy cập công khai, cổng 3000 đã được chuyển lại về Private để bảo đảm an toàn.

4. Năm đặc tính điện toán đám mây theo NIST

1. On-demand Self-service - Tự phục vụ theo yêu cầu

Em tự tạo và khởi chạy GitHub Codespaces thông qua trình duyệt mà không cần yêu cầu quản trị viên cấp phát máy thủ công.

2. Broad Network Access - Truy cập mạng rộng

Em truy cập API qua URL của Codespaces trên máy tính và điện thoại thông qua Internet, minh họa khả năng sử dụng dịch vụ từ nhiều thiết bị khác nhau.

3. Resource Pooling - Gộp tài nguyên

Codespaces cung cấp môi trường với 2 CPU logic và 7.8 GB RAM từ hạ tầng do nhà cung cấp quản lý. Đây là ví dụ về việc khai thác tài nguyên từ hạ tầng dùng chung thay vì sử dụng trực tiếp phần cứng máy cá nhân.

4. Rapid Elasticity - Co giãn nhanh

Môi trường Codespaces có thể được tạo, khởi động và dừng theo nhu cầu. Việc này minh họa khả năng cấp phát và thu hồi môi trường nhanh chóng. Bài thực hành chưa kiểm thử tự động tăng giảm tài nguyên theo tải.

5. Measured Service - Dịch vụ đo lường được

Em sử dụng GitHub Billing Usage để theo dõi tài nguyên lưu trữ và chi phí. Tại thời điểm kiểm tra, hệ thống ghi nhận 0.49 GB-month, chi phí trước ưu đãi $0.03 và số tiền được tính phí là $0.00.

6. Kết luận

Qua bài thực hành, em đã sử dụng GitHub Codespaces để triển khai môi trường Node.js trên đám mây, xây dựng API Hello Cloud bằng Express, kiểm tra truy cập từ điện thoại và thu thập thông số tài nguyên.

Việc so sánh với máy cá nhân giúp em nhận thấy ưu điểm của môi trường đám mây trong khả năng cấp phát, truy cập và quản lý tài nguyên. Đồng thời, các thao tác thực tế giúp em hiểu rõ hơn năm đặc tính điện toán đám mây theo NIST.
